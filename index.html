Умножение одночленов

Аналогичные примеры с подробным пошаговым решением.

Аналогичные примеры

Задание 1

Перемножьте одночлены и приведите к стандартному виду.

−18xy⁵ · 4,8x⁴y²
Подробное решение

Шаг 1. Коэффициенты

−18 · 4,8 = −4,88 = −0,6

Шаг 2. Буква x

x · x⁴ = x1+4 = x⁵

Шаг 3. Буква y

y⁵ · y² = y5+2 = y⁷
Ответ
−0,6x⁵y⁷

Задание 2

Перемножьте одночлены и приведите к стандартному виду.

12ab⁴ · (−a²b³) · 0,5a⁵
Подробное решение

Шаг 1. Коэффициенты

12 · (−1) · 0,5 = −6

Шаг 2. Буква a

a · a² · a⁵ = a1+2+5 = a⁸

Шаг 3. Буква b

b⁴ · b³ = b4+3 = b⁷
Ответ
−6a⁸b⁷

Задание 3

Перемножьте одночлены и приведите к стандартному виду.

−0,4a²b⁵cn+2 · (−0,7a⁵cn+3)
Подробное решение

Шаг 1. Коэффициенты

(−0,4) · (−0,7) = 0,28

Шаг 2. Буква a

a² · a⁵ = a⁷

Шаг 3. Буква b не меняется.

b⁵

Шаг 4. Буква c: складываем показатели.

(n+2)+(n+3) = n+n+2+3 = 2n+5
Ответ
0,28a⁷b⁵c2n+5

Задание 4

Найдите одночлен P.

−x³y² · P = 58x⁸y10
Подробное решение

Шаг 1. Коэффициент

k = 58 : (−1) = −58

Шаг 2. Степень x

3 + m = 8; m = 8 − 3 = 5

Шаг 3. Степень y

2 + r = 10; r = 10 − 2 = 8

Шаг 4. Проверка

−x³y² · (−58x⁵y⁸) = 58x⁸y10
Ответ
P = −58x⁵y⁸
